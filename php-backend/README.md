# SmartPlantBox PHP Backend API

This is the backend API for the SmartPlantBox Android application. It handles user authentication, device management, and password recovery.

## Requirements

- PHP 7.4 or higher
- MySQL 5.7 or higher
- Composer
- SMTP access (Gmail recommended for password recovery)

## Installation

### 1. Install Composer dependencies

```bash
cd php-backend
composer install
